# FOCUSED-ENCOUNTERS v1.1 — симуляция OFF/ON (дни 1–10)

Скрипт: `npm run focused:simulate` (`FOCUSED_SIM_RUNS=1000`). **OFF** — поставляемый контент (флаг выключен); **ON** — тот же контент, переключён только `rollout.focusedEncounters` (диапазон 1–10 из конфигурации). Одни и те же seeds и 7 политик; цели вращаются по seed (order / workshop / alexey), чётные seeds меняют цель в днях 11 и 21. **Флаг в поставляемом контенте остаётся `false`.**

## Правила приёмки (зафиксированы до просмотра результатов)

- Ноль допуска: падения, `FOCUS_POOL_EMPTY`, прогоны не из 120 решений, пропуск `at`, неисполненные `required`-продолжения, расхождения защищённых кандидатов (neutral / probe / development) между ON и OFF на одном состоянии, показ обычной сюжетной сцены без уровня P1–P5.
- Диагностика и слоты: отличие среднего больше 3 стандартных ошибок (SE) помечается «нужен анализ» и блокирует включение, пока не объяснено.
- **Единственное принятое отклонение (решение владельца, 2026-10-08): меньше бросков кубика на прохождение** (≈ −0,2…−0,25 за прогон). Принято при условии, что убыль объясняется ростом запланированных продолжений ранее показанных сцен (`scheduled` растёт не меньше чем на 80% убыли бросков) и не превышает 0,3 за прогон; условие проверяется самим скриптом. Остальные критерии не менялись.

## Что показала симуляция по ходу работы

1. **Первая разметка была неверной** (линии `apprentice` у бытовых сцен Алексея давали P1 и вытесняли стартовые сцены; `c1_liya_letter` показывалась в 35% прогонов вместо 53%) — разметка исправлена до итоговых прогонов.
2. **Бросков меньше** (29,07 → 28,86, −10 SE) — принято, причина подтверждена: `scheduled` +0,179 при убыли 0,202 (88%). Стартовые сцены `c1_neighbor_noise` и `c1_old_bowl` теперь показываются на 25–30% чаще, их продолжения чаще занимают первый свободный слот дня.
3. **Реальные цепочки** (`FOCUSED-ENCOUNTERS-CHAINS.md`) показали, что тексты-«детали» шести сцен главы 2 вытесняли ситуацию — исправлено (только текст, на отбор не влияет).

Тексты после этого прогона менялись (возвраты в бытовых сценах, детали шести сцен, отклики Марты). Проверено, что **ни одно из этих изменений не меняет ни одного розыгрыша**: 280 из 280 прогонов совпали по показам, наборам кубика, истории и фактам с вариантами и без них, поэтому результаты отбора ниже остаются верными для итогового контента.

## Выводы

- **Структура:** 0 падений, 0 `FOCUS_POOL_EMPTY` на реальном контенте при включённом фокусе (в том числе при смене цели в днях 11 и 21), у всех прогонов 120 решений, 0 пропусков `at`, 0 неисполненных `required`, 0 расхождений защищённых кандидатов на ~65 000 сравнений наборов, 0 необоснованных обычных сцен (ни на гранях, ни в прямом отборе). Шесть уникальных карточек в каждом наборе, не более одного probe.
- **Диагностика:** N, W, K, coverage, confidence, доли статусов и стадий, число показанных neutral и probe — в пределах 3 SE (neutral: −0,11 за прогон, 2,8 SE). Единственный помеченный показатель — число бросков — принят владельцем.
- **Содержательный эффект:** нерелевантные показы на гранях 9,4% (OFF) → 0% (ON); доля показов сцен, размеченных на текущую цель, 54,6% → 64,8%; различных обычных сцен за прогон 5,93 → 6,06; различных линий 1,79 → 2,10. Разнообразие не упало.
- **Ограничения:** скриптовые политики, не люди; диапазон только дни 1–10 (11–30 — этап 3); восприятие «наполнителя» оценено прокси-метрикой (см. `FOCUSED-ENCOUNTERS-DIRECT-VS-DICE.md`).
