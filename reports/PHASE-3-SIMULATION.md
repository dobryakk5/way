# Проверка этапов 1–4 под v2.2

Дата: 4 октября 2026. Контент: `mvp-v2.2-alpha.1`.

## Результат

- `npm run check`: проверка контента, TypeScript strict, 79 тестов в 9 файлах — успешно.
- `npm run smoke:phase4`: обе стартовые ветви × оба маршрута второго дня — успешно.
- `npm run simulate -- --write`: 7000 основных прохождений и 400 прохождений с фокусом на грани; ошибок инвариантов: 0.
- Все пять теней подтверждены отдельными воспроизводимыми сценариями с реальными действиями.
- `npm run build`: успешно; основной JS 414,01 kB / 119,86 kB gzip, CSS 7,91 kB / 2,65 kB gzip. PWA: 9 precache entries.
- Браузер, 390 × 844: восемь выборов, намерение, маршрут, последствия, два вечера и завершение среза; консоль без ошибок и предупреждений.

Проверяются 40 карточных решений, все точные слоты, сцены выбранного маршрута, окно озарений 6–8 и их видимый результат, длина портрета 500–900 символов, лимит кризисов и охват обычных ситуаций смешанной политикой. Сценарные тесты отдельно проверяют обе сцены каждого маршрута, taken/expired каждой возможности, отсутствие истечения не предъявленной возможности, идемпотентность, вместимость дедлайнов и сериализацию текущей сцены.

Машинные данные и seeds: [simulation.v2.2.json](simulation.v2.2.json). Это проверка структурной работоспособности, не доказательство литературного качества, удобства на всех устройствах или отсутствия оптимальной стратегии у живого игрока.

## Не проверено и не завершено

Постоянное хранение/импорт, полноценный десятидневный UI, реальный офлайн-запуск на iOS/Android, share-card, финальные иллюстрации и человеческий плейтест. Предыдущие результаты v2.0 находятся в `archive`; оставшийся `simulation.phase3.json` также относится к v2.0.
