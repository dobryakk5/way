# Путь — v2.4

Мобильная браузерная игра о гончаре. Доступны первые **30 игровых дней**: ярмарка, её последствия и новое дело. В день — четыре решения. Ночь позволяет остановиться; перезагрузка продолжает ту же сцену.

Реализованы отдельная цель героя и её пересмотр на днях 11/21, намерение по граням, маршруты, кризисы, обязательные продолжения, честный кубик свободных встреч, ночные снимки и экран «Мой путь» за день / 7 / 30 дней. Ярмарка — сохранённый сюжетный рубеж дня 10. День 30 обозначает границу написанного продолжения.

В контенте 127 карточек, включая 40 новых обязательных сцен и 24 свободные встречи. Тексты учитывают прежние решения, в том числе отказ от эксперимента. Описательные признаки выбора и свидетельства связаны с реальными сценами. Нет оценки личности или награды за распределение времени.

Развитие относится к герою. Реализован переход **Эксперт → Достиженец**: проба, показанное последствие, разбор, перенос в другой контекст и сохранение способа под давлением. Переход закрепляется ночью; прежние способы остаются доступными. Можно пройти все 30 дней, оставаясь Экспертом. Добавлены шесть сцен повторных попыток и четыре сцены Достиженца. Все восемь стадий описаны в данных; остальные переходы пока не написаны.

Наблюдение за логикой героя (v2.4, версия состояния 5): по реальным решениям строится профиль восьми способов действия, отдельный от подтверждаемого развития. Новая игра начинается без стадии; первый способ появляется после устойчивого наблюдаемого центра. Необязательный вопрос о мотиве — не чаще раза в день. Адаптация подбора сцен по профилю реализована, но выключена до калибровки. Подробности и находки: [reports/IMPLEMENTATION-v2.4-HERO-PROFILE.md](reports/IMPLEMENTATION-v2.4-HERO-PROFILE.md).

Сохранения известных v2.3 и v2.4 автоматически мигрируют в состояние версии 5 с отдельным сохранением оригинала. Открытая карточка, мир и история не пересчитываются; прежняя стадия Эксперта остаётся авторской.

## Запуск

```bash
npm ci
npm run dev
npm run check
npm run simulate -- --write
npm run simulate:development -- --write
npm run build
npm run preview
```

`SIM_RUNS=100 npm run simulate` — короткая симуляция. Полная: 1000 прохождений каждой из семи политик и дополнительные сценарии. Отчёт: [simulation.v2.4.json](reports/simulation.v2.4.json).

`npm run simulate:profile -- --write` — арифметическая симуляция профиля (8 целей, смешанные, недостаточные, адаптивные траектории) и проверка достижимости на реальном контенте. `npm run profile:calibration -- --write` — покрытие, баланс, тайминг Эксперта, шаблон слепой проверки редактора.

`npm run simulate:development -- --write` — пять траекторий по 100 seed: контроль, отступление, освоение, повторная попытка и поздний переход. Отчёт: [development.v2.4.json](reports/development.v2.4.json).

## Архитектура

- `src/engine`: чистые переходы, планировщик, цель, встречи, ночи, расчёт периодов.
- `src/content/data`: календарь, карточки, эффекты, авторские продолжения и признаки действий.
- `src/persistence`: версионированная проверка, транзакции IndexedDB, корректная резервная копия, сохранение повреждённого оригинала и Web Locks.
- `src/store`: презентация сцен, последовательная очередь автосохранений и статус записи.
- `src/ui`: мобильные карточки, ночь, цель, кубик и доказательные записи.

Один профиль на origin браузера. Для переноса адреса/порта нужен отдельный механизм экспорта, которого в этой версии нет. При ошибке записи сессия остаётся доступной; перед закрытием нужно повторить сохранение. Вторая вкладка блокируется. При повреждении данные сохраняются и предлагается восстановление из предыдущей корректной копии.

Технологии: React, TypeScript strict, Vite, Zustand, Framer Motion, Vitest, Zod, IndexedDB. Zod проверяет и контент при сборке, и загружаемые локальные сохранения. `fake-indexeddb` используется только в тестах.
